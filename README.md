# Shopping Cart

A mock shopping cart application built as part of [The Odin Project](https://www.theodinproject.com/).

## Features

- Product browsing using FakeStore API
- Adjustable quantities and shopping cart management
- Real-time cart counts and price calculations
- Responsive design with multi-page navigation

## Built With

- React, React Router, and Vite
- JavaScript and CSS
- FakeStore API
- Vitest and React Testing Library
